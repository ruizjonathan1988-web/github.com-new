# Basse

Égaliseur pour casque FiiO FT1, sur Galaxy Z Fold 8 et box Android TV.

- 22 familles, 186 réglages (styles et sous-styles), plus des modes cinéma, séries, sport, nuit et jeux.
- Correction propre au FT1, plus grave et aigus réglables, avec préampli automatique et limiteur.
- Mode global (tout le son) quand l'appareil l'autorise, sinon les lecteurs qui déclarent leur session audio (Samsung Music, Spotify, YouTube Music, VLC…).
- Le thème change selon le style choisi : ondes au BPM pour l'électro, ondulations, spectre pour le rock et le metal, salle obscure en mode cinéma.
- Les valeurs PEQ s'affichent pour les recopier dans FiiO Control (BTR13).

Les styles se modifient dans `tools/gen_styles.py`. Chaque push sur `main` compile l'APK et le publie dans Releases.
